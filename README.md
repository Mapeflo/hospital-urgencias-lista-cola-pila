# Hospital Urgencias - Sistema con Lista, Cola y Pila

**Ejercicio 18** - Caso: Hospital de Urgencias

## Descripción
Sistema de gestión de pacientes de urgencias utilizando tres estructuras de datos personalizadas:

- **Lista**: Registro general de todos los pacientes
- **Cola**: Pacientes pendientes de atención (FIFO)
- **Pila**: Historial de pacientes atendidos + deshacer (LIFO)

## Funcionalidades
1. Registrar paciente
2. Ver todos los pacientes registrados
3. Ver pacientes pendientes
4. Procesar siguiente paciente
5. Ver historial de atendidos
6. Buscar paciente por código triage
7. Cancelar paciente pendiente
8. Deshacer último procesamiento
9. Ver cantidad de elementos

## Cómo ejecutar
Ejecutar la clase `SistemaHospitalUrgencias`
